# 浴山快排濾網使用指南 C 版

獨立預覽網址：https://survey.mieloo-corp.com/strainer_guide/c/

B 版仍保留在上一層 `strainer_guide/`，本版使用独立程式與素材，未修改 B 版或儲存庫設定。

順序：放入安裝 → 清倒廚餘 → 排水與止水 → 清潔維護與 Q&A → 規格說明。
首頁提供「開始安裝」與「遇到問題」，產品介紹、完整影片及尺寸確認收在 Q&A 下方。
完整影片採站內彈窗，點擊才建立播放器並載入影片，關閉即暫停。

文案修改：`content.js`。內容檢查：`node scripts/check-content.mjs`。
