# 以後主要修改這一份：content.js

網站：https://survey.mieloo-corp.com/strainer_guide/

這份網站已將常用內容集中在 **[content.js](./content.js)**。一般改文字、連結、影片步驟，不必修改 index.html，也不必重傳整個網站。

## 在 GitHub 修改

1. 進入 `strainer_guide`，打開 `content.js`，按鉛筆編輯。
2. 找到要修改的文字，只改引號內的內容。
3. 檢查修改差異，再按「Commit changes」儲存至 main。
4. 等 GitHub Actions 的 Pages 發布完成，再重新整理網站。若仍顯示舊內容，使用強制重新整理；GitHub 的快取也可能需要幾分鐘更新。

請只修改 `strainer_guide` 內的內容，無須調整儲存庫根目錄、問卷、尺寸校驗或 Pages 設定。

## 改文字的例子

例如把：

```js
"title": "從安裝到每日使用。"
```

改成：

```js
"title": "你的廚房使用指南。"
```

保留原本的引號、逗號、大括號與中括號。文字可直接使用中文引號「」。若要在文字內放英文雙引號，請寫成 `\"`；換行可寫 `\n`，但一般段落在網頁上仍會自動折行。

不要改動 `fit`、`install`、`use`、`empty`、`care`、`daily`、`deep` 等識別名稱，也不要修改章節的順序與編號。影片保持每支三個步驟。

## 修改影片

- `file`：影片路徑，例如 `./assets/video/install.mp4`。
- `poster`：未播放時的封面路徑。
- `title`：影片或步驟名稱。
- `text`：該步驟下方的說明。
- `at`：靜態預覽的停格秒數，目前用於影片下方「日常清洗／深度清潔」分類切換。
- `start`：點擊影片內步驟按鈕時，從這一秒開始播放，並接著播到結尾。連續播放到這一秒時，也會自動選取該步驟。

播完後仍顯示中央重播圖示；點任一步驟也可直接重播該段。點影片本身可播放或暫停。

`at` 和 `start` 是數字，不加引號。第一個 `start` 為 0，後續依序增加；`at` 必須落在該步驟的播放區間，且短於影片總長。更換影片時請一併確認三個時間點與封面。

把新影片與封面上傳至 `assets/video/`，再改 `file`、`poster`。建議使用新的英文檔名，避免訪客讀到舊檔快取。只需上傳變更的檔案。

## 編輯 Q&A

每題包含 `question`（問題）與 `answer`（回答區塊）：

```js
{
  "question": "想新增的問題？",
  "answer": [
    { "type": "paragraph", "text": "第一段回答。" },
    { "type": "list", "items": ["第一步", "第二步"] }
  ]
}
```

`paragraph` 是段落，`list` 是編號步驟。可選的 `heading` 是該段的粗體開頭，`newLine: true` 會讓粗體後換行。不需要寫 HTML。

## 哪些仍需要程式修改

顏色、排版在 CSS；3D 零件位置、尺寸、粒子、水流、清潔特效和互動按鈕在各自程式中。這些涉及畫面與行為，仍需測試後更新。`index.html` 現在主要保留頁面結構與模型容器。

常用內容由瀏覽器讀取 content.js；index.html 中的初始搜尋摘要與標題是靜態備援。如果日後要同步調整搜尋引擎不執行 JavaScript 時讀到的摘要，也需更新這兩個備援欄位。

累計數字目前仍為已核實的 **4739** 歷史基準（2966 份問卷＋1773 次尺寸確認），尚未串接計數後端。這次整理沒有新增自動計數。不要把修改數字當成實際新增使用人次。

## 可選的發布前檢查

若有 Node.js，在儲存庫目錄執行：

```sh
node strainer_guide/scripts/check-content.mjs
```

會检查內容格式、章節識別、連結、影片檔案與時間排序。發布後，仍要實際點選三支影片的步驟並查看手機排版。
